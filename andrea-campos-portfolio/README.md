# Andrea Campos — GitHub Pages Portfolio

## Publish
1. Create a new GitHub repository (recommended: `yourusername.github.io`).
2. Upload every file and folder in this package to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will show your live site URL.

## Before publishing
Open `index.html` and replace `YOUR_EMAIL@example.com` with your email and `https://www.linkedin.com/` with your actual LinkedIn URL.

Put your final CV PDF in `assets/` and name it exactly `Andrea-Campos-CV.pdf` so the Download CV button works.

No server, database, build tool or paid hosting is required.
